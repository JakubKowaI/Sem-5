            break;
        }
        {
            //Przejdź znalezioną ścieżką powiekszającą od końca (t) i powiększaj o znaleziony pathFlow
        }

    }
    return maxFlow;
      \caption{}
\end{algorithm}
\subsection{Złożoność}
n --- liczba węzłów.\\
m --- liczba krawędzi.\\
Pętla wykona się najwyżej n razy bo każda ścieżka powiększająca wyczerpuje jedną z krawędzi, a ścieżki od s do t są ograniczone przez n, więc możemy wyczerpać najwyżej n ścieżek. O(n)\\
BFS jest O(m) (ilość krawędzi)\\
Powiększanie przepływu jest O(m), bo najdłuższa ścieżka powiększająca może być długości m.\\
Łącznie dostajemy O($n\times m \times m$), czyli \textbf{O($\text{\textbf{nm}}^{2}$)}.

\subsection{Złożoność}
Algorytm w każdej fazie wykona BFS o złożoności O(m) oraz maksymalnie n DFS o złożoności O(m). Wiemy, że graf nie będzie cykliczny, co oznacza, że po każdej fazie będziemy nasycać przynajmniej jedną krawedź. Uświadamia nam to, że faz może być najwyżej n (brak cykli w grafie). Więc ostatecznie otrzymujemy O($n \times (m + n \times m)$), co daje nam: \textbf{O($\textbf{n}^{2}\textbf{m}$)}.

\section{Zadanie Hiperkostka} 
\subsection{Opis zadania}
Dla parametru k zbudować skierowaną k-wymiarową hiperkostkę $H_{k}$ o $2^{k}$ wierzchołkach opisanych k-bitowymi ciągami.
Krawędzie łączą wierzchołki mające dokładnie jedną jedynkę w zapisie bitowym i skierowane są od wierzchołka o mniejszej wadze Hamminga do tego o większej wadze (mniejsza ilość jedynek $\rightarrow$ większa ilość jedynek).
Pojemność każdej krawędzi (i,j) losowana jest równomiernie z \{1,\dots,$2^{l}$\}, gdzie l = max\{H(e(i)), Z(e(i)), H(e(j)), Z(e(j))\} (H — waga Hamminga, Z — liczba zer (k-H(e(i)))).
